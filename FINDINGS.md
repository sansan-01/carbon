# Security and robustness audit

Carbon is a deployed Next.js application fork. The checkout contains one snapshot commit, so file attribution relies on visible fork changes and the supplied deployment scope. Locations refer to the original snapshot. Dependency findings use the resolved Yarn versions and account for whether the affected feature is present in this application.

The credential scan covered tracked source, configuration, CI, documentation, the lockfile, and printable strings in binary assets. The Cypress recording key in `.github/workflows/validate.yml` appeared in inspection output before redaction and remains in the baseline commit. Its validity was unverified. The tracked images are application assets, and the tracked tree contained no generated build output.

Verification covered YAML and shell syntax, deployment JSON, ignore patterns, JSX parsing and isolated checks for editor initialization and navigation. This checkout had no installed project dependencies, so the Next.js build and Cypress suite remain unverified. The dependency review matched the lockfile against public advisories and did not run a registry audit.
